# 食时界面清单（基于当前设计稿分析）

## 1. 统计口径
- 本清单统计“需要开发的业务界面”，不含设计规范页、竞品分析页等展示型页面。
- 由于 Figma MCP 学生席位调用限额，当前为第一版盘点；已覆盖核心业务流。

## 2. 界面总数（第一版）
- C 端（用户端）核心界面：8 个
- B 端（物业端）核心界面：6 个
- 合计核心业务界面：14 个

## 3. C 端界面（用户）
1. 登录页（已确认）
2. 首页（已发现标签）
3. 寻店结果页（列表）
4. 寻店结果页（地图）
5. 商场详情页
6. 店铺详情页（示例：精品咖啡）
7. Plan B 备选方案页
8. 组队投票页

说明：
- “寻店结果页”在设计中体现了至少 2 种视图（列表/地图），按独立可达界面计为 2 个。
- “Plan B”属于独立决策分支，不并入普通详情页。

## 4. B 端界面（物业）
1. 首页
2. 工单页
3. 数据统计页
4. 巡检页
5. 工单详情页
6. 个人页

说明：
- 设计稿中该模块强调多端协同（手机/平板/桌面），当前按“功能界面”去重计数，暂不按设备倍增。

## 5. 非业务界面（不计入开发界面数）
- 设计规范
- 竞品分析
- 多端交互说明区（概念展示部分）

## 6. 需要二次核验的项
- 登录链路中的“立即注册/忘记密码”是否已有独立高保真页面。
- C 端是否存在“个人中心/订单/历史投票”等补充页面未展示在当前节点区域。
- B 端是否有二级页（如统计详情、巡检详情）需要纳入一期。
